**上層：** [README](../../README.md) 的待執行路線是主清單；此文件是唯一詳細進度來源。

**附件：** [介面盤點](2026-10-01-rebuild/inventory.md)、[缺陷與沿用盤點](2026-10-01-rebuild/behavior.md)、[審查與接手入口](2026-10-01-rebuild/review.md)。

## 全域約束與完成定義

- 不修改 reference checkout，不複製原程式碼、配置或憑證；以行為作參考，自行實作。
- 原 README 不是完整規格；controller、service、schema、Vue 呼叫方共同定義待盤點行為。
- 使用 Next.js + TypeScript、FastAPI、PostgreSQL；重新設計 REST 契約。Next.js 不持有業務權限判定責任。
- 原 API 的 route 不要求相容，功能、角色與錯誤情境必須有映射。待決去向不得當成已刪除。
- 完成定義：附件每項有最終去向、新 endpoint/page/model/test 證據；pytest、前端 typecheck/build、Playwright 與 migration 驗收通過；設計與程式碼審查完成；真實 provider 驗收未跑不得宣稱完整上線。
- 每階段開工前需有核定的 payload、schema、權限矩陣與逐步驗收命令。下面 2–7 是階段範圍，需在該階段開工前展開為可執行子計畫；不得按摘要直接開工。

## 不變量

| 不變量 | 預計依賴機制 |
|---|---|
| API 永遠自行驗證 principal 與 resource，不依賴前端隱藏按鈕 | api/auth、api/policies、所有路由、WebSocket handshake |
| 私人／團隊圖片不洩漏給無權限使用者 | picture query、download/storage URL、analysis、sharing、cache |
| DB transaction 不涵蓋物件儲存 | upload job、補償清理、quota、delete worker |
| 併發上傳／替換不能使配額計算錯誤，retry 不重複計帳 | quota update、idempotency、picture replacement |
| 協同編輯沿用單一編輯者語意；狀態與鎖是明確設計 | websocket registry、lease、disconnect/reconnect |
| wire ID 是 string，避免 JavaScript 整數精度問題 | Pydantic schemas、generated client、WebSocket schemas |

實作後補上檔案路徑；修改不變量時需列出所有消費端同步修改。

## 規模與範圍

盤點腳本產出 53 個 REST endpoint、17 個前端 route、4 個 SQL table、5 個 WebSocket message type；來源與重跑指令見附件。這是入口清單，不代表完整業務 payload 已盤點。

- 做：註冊登入、管理員操作、會員兌換、公共圖庫、檔案與 URL 上傳、批次匯入、審核、標籤分類、圖片下載、私人與團隊空間、搜尋、批次編輯、詳情 URL 分享／QR、裁切、六種分析、協同編輯、以圖搜圖與 AI 擴圖。
- 不做：Vue starter About page、公開 file/test 端點；測試能力搬到 integration suite（Will 已確認 D5）。
- 延後：分庫分表、二級快取、專用高效佇列；當基準測試證明單 DB、單一快取或普通 worker 成為瓶頸再選型。不是功能刪除。
- 外部服務採 adapter；單元測試 fixture 不代表實際整合完成。

- [ ] **7. 收尾與部署**（被擋於：2–6；部署環境與成本決定）

  - 消費端：`rg -n 'http|api/v1|WebSocket|storage' web api`；附件所有入口逐項對照 test。
  - 不能動：未授权的外部部署；不能忽略未跑的檢查。

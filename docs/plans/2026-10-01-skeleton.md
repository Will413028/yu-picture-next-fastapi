## 契約與結構

- `api/`：FastAPI app factory，lifespan 管 engine；同步 SQLAlchemy + psycopg 由同步 endpoint/thread pool 呼叫，不在 async event loop 執行 blocking SQL。
- `GET /api/v1/health`：200 `{"status":"ok"}`，不碰 DB。
- `GET /api/v1/ready`：實際 `SELECT 1`；200 `{"status":"ready","database":"connected"}`，SQLAlchemy DB failure 回 503 `{"status":"unavailable","database":"disconnected"}`。不回傳 DSN/exception。
- `web/`：Next.js App Router server component，server-only readiness client，no-store 與 4 秒 timeout；顯示 connected、disconnected（API 503）、unreachable（API connection/timeout 或不合契約）。API URL 是 server runtime 配置，不以 NEXT_PUBLIC 暴露。
- PostgreSQL 僅綁定 localhost:55479，隔離 compose project；本機開發用 trust，不是正式部署配置，容器內不需密碼。不得重用其他專案 DB。原定55439占用，改用已探測可用的55479。
- Alembic 初始空 revision 只建立 migration 版本基線，不增加假的業務資料表；步驟 2 才建立 user schema。
- 原回應 envelope 不沿用（D2 已核准 REST 重設）。不移植舊健康檢查只回固定字串的 readiness 語意。

## 執行與驗收

在 repo root 執行 Make targets；每條使用絕對 root 派生命令。

1. 建立 manifests、lockfiles、app、migration、首頁、compose、測試与 Makefile；`make install` 安裝依賴。
2. `make db-up` 建立本專案容器，`make migrate` 執行空基線；`make test-api` 同時跑 unit 及 PostgreSQL integration。
3. `make typecheck`、`make build`；`make test-e2e` 啟動 API 和已 build 的 Next.js，透過真實瀏覽器讀 SSR 結果，不 mock API。
4. E2E 串行：DB 上線時頁面成功 → 停止本專案 DB → readiness=503、liveness=200、首頁 unavailable → 重啟 DB，頁面回復 connected。finally 必須恢復 DB。另起首頁 server 指向無服務的 loopback port，驗證 API 無法連線仍可 SSR；timeout 用隔離 HTTP fixture + 縮短 deadline 驗證，並斷言正式 deadline=4000ms，不取代真 DB E2E。
5. `make test-mutation`：以依賴替換實際 DB check 為固定成功，在 unavailable engine 上重跑既有負向測試，必須失敗；禁止修改共享 source 或 DB credentials。
6. CI 完整順序：`make install-frozen` → `make browser-install` → `make check` → always compose stop；check 自行 db-up（有界健康等待60秒），依序 migration、lint、pytest、client unit、typecheck、build、E2E、mutation。mutation 外層先確認原負向 regression 通過，再只接受 pytest TESTS_FAILED（不是收集／工具錯誤）作為成功 killed mutation。CI 固定 Python 3.13／Node 24／pnpm 與 uv 版本、frozen lockfile，使用相同 compose 與 Make targets。
7. 独立程式碼 review 與 design-review，逐項處理，最後核對指令檔／README／主計畫與 git diff。

停止條件：依賴下載未授權；本專案 port/container 衝突；Docker/工具鏈不相容；任何驗收失敗。只操作本專案服務，不 kill 其他程序。未執行的 CI 遠端跑次不宣稱完成。

回滾：本階段新程式未上線，可回復本階段檔案；本機 DB 為新獨立 volume，停止服務不刪 volume。不得執行 down -v 或刪任何原資料。
